# CWE-918: Server-Side Request Forgery (SSRF)

## Description
The scrape-fragrantica edge function accepts user-supplied URLs and queries, then fetches them server-side without adequate validation.

## Examples in Codebase
- `supabase/functions/scrape-fragrantica/index.ts` accepts `url` parameter and passes to `fetch()`
- `query` parameter is interpolated into a search URL without allowlist
- No domain restriction on fetched URLs

## Remediation
- Implement URL allowlist (only fragrantica.com domains)
- Validate and sanitize all user inputs before use in fetch
- Use a URL parser to extract and validate the hostname
