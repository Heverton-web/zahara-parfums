# CWE-862: Missing Authorization

## Description
The application grants administrative access based solely on authentication status, without verifying the user's role or permissions.

## Examples in Codebase
- RLS policies use `auth.role() = 'authenticated'` — any logged-in user gets full CRUD
- `AdminLayout.jsx` checks only `user` truthiness, not user metadata/role
- No role-based access control in the database or application layer

## Remediation
- Implement role-based access control (RBAC)
- Check user metadata for admin role in RLS policies
- Add server-side role verification
