# CWE-798: Use of Hard-coded Credentials

## Description
The application contains hardcoded admin credentials in source code files that are committed to the repository.

## Examples in Codebase
- `scripts/create-admins.mjs` contains plaintext email/password pairs for admin accounts
- Shared password across multiple admin accounts

## Remediation
- Remove hardcoded credentials from source code
- Use environment variables or a secrets manager
- Implement unique passwords per admin account
- Add `.env` to `.gitignore` and rotate any exposed credentials
