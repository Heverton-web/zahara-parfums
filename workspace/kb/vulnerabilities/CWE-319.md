# CWE-319: Cleartext Transmission of Sensitive Information

## Description
Sensitive data is transmitted over unencrypted channels.

## Examples in Codebase
- `src/lib/tracking.js` calls `http://ip-api.com/json/${ip}` (HTTP, not HTTPS)
- IP addresses and location data transmitted in cleartext

## Remediation
- Use HTTPS for all external API calls
- Replace `http://ip-api.com` with `https://ip-api.com`
